# Bilgisayarım Neden Yavaş Cevap Makinesi

## Giriş

Bu proje, insanlık tarihinin en büyük sorularından birine cevap vermek için yaratılmıştır: **Bilgisayarım neden yavaş?**

Yıllar süren (asılında 15 dakikalık) araştırmalar sonucunda, en ileri düzeyde bilimsel yöntemler (rastgele seçim) kullanılarak geliştirilmiş bu makine, size her seferinde farklı, absürt ve son derece tatmin edici olmayan cevaplar verir.

## Özellikler

- %100 gerçek çalışan Python kodu
- Her çalıştırmada yeni bir yavaşlık nedeni
- Bekleme süresi dahil (gerçekçilik için)
- Hiçbir şey düzeltmez, sadece açıklar
- Ücretsiz, açık kaynak, ruhunuzu satmanız gerekmez

## Kullanım

```bash
python yavaslik_cevaplayici.py
```

Evet, bu kadar. Daha basit olamazdı. Zaten bilgisayarınız yavaş, karmaşık şeyler istemeyin.
